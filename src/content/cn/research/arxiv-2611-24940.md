过去一年，机器人策略的两条路线在分叉。视频世界-动作模型把未来画面和动作一起生成，泛化与数据效率都不错，但继承了视频生成器的沉重算力；潜在空间策略绕开像素，却通常把中间特征对齐到某个冻结的目标编码器，未来预测于是和 VLM 自己的表征脱钩。Z-sight 的立场很直接：既然 VLM 已经在自己的视觉 token 空间里看当下，那就让它在这个空间里想未来。

这不是措辞上的统一，而是训练目标上的统一。预测头不再重建画面，也不再向外部编码器的特征回归，而是直接预测 VLM 下一时刻会看到的那些空间 token。感知与预演共用一套坐标系，中间少了一次语义翻译。

### 核心创新

架构上是混合 Transformer：VLM 主干负责多模态理解，一个前瞻专家在视觉 token 空间里推演未来的空间 token，一个连续动作专家输出动作块，三者在推理时联合去噪。未来 token 与动作不是先后两阶段，而是同一次去噪过程的两路输出，动作生成因此可以直接读到「我这样做之后画面会变成什么样」的中间状态。

第二个设计选择是拒绝像素重建。视频世界模型的代价主要来自解码回像素，而 Z-sight 把监督信号留在 token 层面，既省掉了生成器的参数与延迟，也避免了重建损失把表征拉向「看起来像」而不是「对控制有用」。

训练数据混合了人类视频与机器人轨迹：人类视频提供场景如何演化的先验，机器人轨迹负责把动作与视觉后果绑定起来。这种混合是它能在人形平台上取得大幅增益的前提之一。

### 结果

SIMPLE 上成功率 81.9%，比最强基线高 9.6 个百分点。更具指标意义的是 Unitree G1 的六个任务：平均成功率 73.3%，比基线高 20.0 个百分点。人形平台的动作空间大、平衡约束强、观测抖动明显，20 点的提升说明这套表征迁移到高自由度本体时没有散架。

效率数据同样关键：每个动作块 110 毫秒，意味着联合去噪后的推理频率仍落在分块控制的可用区间。作者还报告在桌面操作基准上保持竞争力，说明统一架构没有以牺牲成熟场景为代价。

### 局限

摘要没有给出 G1 六个任务各自的成功率分布和失败模式，也没有说明基线的参数量、训练数据是否对等，「+20 点」的含金量因此无法完全核对。

110 毫秒一块对抓取放置足够，但对高动态任务（接抛、快速避障、人机近距离协作）仍然偏慢，论文没有讨论这一边界。前瞻窗口有多长、未来 token 的误差会不会在长程任务里累积，也未报告。

### 产业启示

对人形机器人团队，这篇最重要的信息是预算层面的：世界模型不必等于一个独立的视频生成器。把预测压回 VLM 自己的 token 空间，模型规模、显存和延迟都可控，感知、预测、控制三套系统也不必再各自维护一套表征。

架构上的启示更长远：VLM 的视觉 token 空间本身就是一个可用的预测空间。沿着这条线，下一代 VLA 的竞争点会从「有没有世界模型」转向「世界模型建在什么表征上、前瞻多长、误差如何校正」。

需要保留的判断是，token 空间的未来是语义级而非几何级。对需要毫米级对位的装配、插接任务，这套预测是否够用，本批实验没有回答。
