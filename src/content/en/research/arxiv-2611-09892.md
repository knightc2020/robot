Robot manipulation has spent years converging on a single recipe: collect large demonstration datasets, train a specialist policy, and hope the coverage is wide enough. Vision-language-action models and world-action models differ in architecture but share that premise. This paper asks a blunt question — what if the generalist model should not be trained to output actions at all, but simply be allowed to operate the robot the way it operates software?

The authors call the resulting class agentic manipulation policies, or AMPs. A generalist AI model observes the scene, decides on an action, observes the result, and repeats, adapting as the task unfolds. AMP1 is their reference harness: the same loop, unchanged, across single-arm, bimanual and mobile manipulation.

### Core innovation

The contribution is less a new network than a disciplined reframing of where intelligence sits. Instead of distilling robot behaviour into weights, AMP1 exposes the manipulator as an interface the model can drive, and lets a closed-loop agent figure out the control strategy at test time.

Three design choices make that practical. First, the harness is embodiment-agnostic: the same observation-action loop covers one arm, two arms and a mobile base, so capability is not re-engineered per platform. Second, no primitive skill library is supplied — no grasping, pushing or placing routines. The agent has to discover that it can search for occluded objects, use one object as a tool for another, or recalibrate a camera when its view is misleading. Third, an optional persistent memory store carries experience across episodes, turning a stateless reactive loop into something that improves with deployment.

That last point matters strategically. A memory representation is a far cheaper way to accumulate competence than another thousand teleoperated demonstrations, and it keeps the underlying model frozen.

### Results

The headline numbers are unusually direct. On RoboLab-120, AMP1 reaches 85.6% zero-shot success, against 49.2% for the best VLA baseline and 42.9% for the best world-action model, with no demonstrations or task-specific training.

The real-world evaluation is the more persuasive half: 104 successful trials out of 108, spanning twelve tasks and three robot instances, corresponding to a 20x reduction in failure rate relative to a strong VLA and 15x relative to a WAM. Those are not cherry-picked simulation episodes; they are physical trials on multiple machines.

Memory adds a second, independent gain. On RoboDojo bimanual tasks, the augmented harness with a cross-episode memory representation lowers failure rate by 4.6x compared with zero-shot deployment. The paper's analysis argues that AMPs are substantially more general and robust than specialist policies, and that the gap comes from adaptation during execution rather than from a better action prior.

### Limitations

The abstract reports aggregate success, not per-task variance, seed counts or confidence intervals, and 108 trials across twelve tasks is a small sample per task. Agentic loops are also slower and more expensive per step than a single forward pass through a policy: every action involves model inference and a closed observation-action cycle, which the paper does not cost out in latency or compute.

Safety and predictability are unresolved. A specialist policy fails in ways that are at least statistically familiar; a generalist agent that improvises strategies is harder to certify, and the paper does not address what happens when its plan is confidently wrong near a person or a fragile object.

The harness is also doing real engineering work that the framing understates. Exposing a robot as a reliable interface — observations, action space, error handling, camera calibration hooks — is exactly where integration effort moves, and it is not free.

Finally, the benchmarks are the authors' own or recently introduced, so independent replication on established suites is still missing.

### Industry implications

If this result generalises, the economics of robot learning shift. Demonstration collection is a large, recurring, embodiment-specific cost; harness engineering is a one-time software investment that can be reused across arms, bases and tasks. A frozen generalist model plus a memory store also means capability can improve through deployment data without retraining the policy.

The near-term winner is probably not a humanoid doing everything, but integration-heavy settings — labs, warehouses, service robots — where tasks vary enough that specialist policies are uneconomical but the environment can be instrumented and supervised. The bottleneck becomes reliability engineering: latency budgets, guardrails, and a principled answer to "what does the agent do when it does not know?"

The paper's deeper claim is architectural. If generalist models can close the loop on real hardware, then the differentiator is no longer the size of the action dataset but the quality of the interface and the memory that surrounds the model.
