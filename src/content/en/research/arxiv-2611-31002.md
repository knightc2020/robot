Coding agents that control robots through executable programs have become one of the more convincing routes to embodied intelligence. The trouble is what surrounds them. Software agents are post-trained inside vast, executable, automatically graded environments; robot agents are still measured on small hand-built benchmarks, mostly in-distribution, where a policy can look competent and still fail the moment a scene changes. The bottleneck is not the model architecture so much as the absence of an environment layer that can be generated, reset, verified and scaled the way code sandboxes are.

RoboUniverse-10K is an attempt to build that layer. Starting from ordinary real-world videos, an automated real-to-sim pipeline reconstructs interactive physics scenes, and a quality-assurance stage filters them. The result is 10,807 environments that can be reset and graded, each wrapped in an isolated, Harbor-compatible harness that hides privileged simulator state and the grading logic from the agent. That last detail matters: if the agent can read the answer key or the exact object pose, a success rate says little about sensing and control in the real world.

### Core innovation

The contribution is infrastructural rather than architectural, and it has three parts.

First, scale with verification. Ten thousand-plus environments is only useful if they are trustworthy, so the pipeline pairs automated construction with an explicit QA filter rather than accepting every reconstruction. Second, a held-out benchmark. Five hundred tasks are reserved and expert-verified to form RoboUniverse-Verified, giving a zero-shot measure that was never part of environment construction. Third, a data-and-model release: roughly 17K multi-turn trajectories totalling 0.79B tokens, generated with a frontier model, are used for full-parameter supervised fine-tuning of an open Qwen3.6-35B-A3B base, producing RoboUniverse-35B-A3B, alongside the RL-ready environments.

The framing is deliberate. The authors call this the scaling era of agentic robotics because the environments are meant to support large-scale reinforcement learning later, not just evaluation now.

### Results

The evaluation first exposes a sharp capability gap. Across 11 closed- and open-source models, frontier systems reach 85.8% success, while open-source baselines land between 2.6% and 10.0%. The failures concentrate in low-level grasping, deformable-object manipulation and post-contact physical control, which is precisely where an agent must close a perception-action loop rather than emit a plausible plan.

Fine-tuning on the collected trajectories moves the open model substantially: zero-shot success on RoboUniverse-Verified rises from 0.8% to 21.2%. That is still far from frontier performance, but the direction is informative, and the tuned model also completes tasks zero-shot on LIBERO-MAX, RoboCasa, RoboTwin 2.0 and a real Franka arm, suggesting the supervision teaches transferable interaction rather than overfitting one simulator.

### Limitations

The absolute numbers need context. A 21.2% zero-shot rate is an improvement, not a solved problem, and the gap to 85.8% remains large. The fine-tuning data was generated with a frontier model, so the student inherits both its strengths and its blind spots; how much of the gain is environment diversity versus teacher quality is not separated in the abstract.

The real-to-sim pipeline also inherits the physical fidelity limits of reconstruction from video. Contact-rich and deformable behaviour, exactly the categories where open models struggle, are the hardest to reproduce faithfully, so simulated success may still overstate real-world reliability. Real-robot evidence is reported as zero-shot task completions on a single Franka arm, without the breadth of the simulated suite.

### Industry implications

For teams building robot agents, the practical value is a reusable environment layer. Instead of hand-authoring a benchmark per task family, a real-to-sim and QA pipeline that turns video into resettable scenes changes the economics of evaluation and, eventually, of RL post-training. Hidden grading logic and isolated harnesses also make the numbers harder to game.

The open release of both environments and model is the more strategic move. It gives the field a shared substrate for comparing agentic policies and a starting checkpoint for groups that cannot train a frontier planner themselves. If the environments hold up under external use, the contribution outlasts any single model result in this batch.
